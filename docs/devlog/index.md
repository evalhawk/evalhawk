# Dev log

A short entry for every finished task: what was built, the idea behind it in plain words,
what was surprising, and where to learn more. It's our shared memory, and a public record of
what each of us built and learned.

## How to add an entry

1. Copy [the template](template.md) to `docs/devlog/YYYY-MM-DD-<card>-<slug>.md`, for example
   `2026-10-02-S1-wilson-interval.md`.
2. Fill it in. Aim for a 5-minute read, and explain it simply first.
3. Add it to the list below (newest first) and to `nav` in `zensical.toml`, in the same PR as the code.
